# Till The End -- Game Reference

Complete reference for all weapons, abilities, skills, and traits in the game.

## Rarity System

| Rarity | Base Chance | Color | Symbol |
|--------|-------------|-------|--------|
| Common | 50% | Silver-white | C |
| Rare | 20% | Blue | R |
| Mythic | 10% | Pink-magenta | M |

Luck trait adds +5% to both Rare and Mythic appearance chances per level.
